# 蓝牙开锁修复验证

本次修复钥匙请求竞态、旧缓存优先、错误分类、失败信息丢失。点击开门重新获取并等待当前订单钥匙，插件返回失败后调用 stopAllOperations 清理；不自动重复开锁。

35 秒无回包仅提示结果尚未确认，继续阻止新开锁。插件文档明确停止操作不能保证中断连接，所以不把超时当作确定失败。迟到成功仍同步入座。清理失败则保持全局操作保护，需要重新启动小程序或店长协助。

失败诊断沿用 door_logs.fail_reason（最多 200 字），附带阶段、错误码、耗时、系统和插件版本；没有数据库结构变更。上报失败被捕获，不影响已经完成的物理开锁；目前没有离线日志补传，网络断开时可能缺记录。
