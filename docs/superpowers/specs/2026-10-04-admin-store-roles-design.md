# 后台总部 / 店长角色设计

日期：2026-10-04  
状态：已确认并实现首版

## 目标

同一套管理后台：

- **总部（hq）**：看全部门店与全局配置（与现网一致）
- **店长（store）**：只绑定一家门店，仅可查看与操作本店数据

服务端强制鉴权；隐藏菜单不能作为唯一授权手段。

## 数据

`admin_users` 新增：

- `role`：`hq` | `store`，默认 `hq`
- `store_id`：可空；`store` 角色必填

现有账号迁移为 `hq`。

## 店长可用模块（本店）

数据总览、收款管理、实时占座、门店资料编辑（不含改收款账户绑定/新建门店）、营业日历、价格、座位、预约订单、门锁、开门记录、套餐购买、期限卡（本店）、团购映射、兑换记录。

## 仅总部

管理员、收款账户、新建门店、全局用户/钱包/积分/邀请、优惠券、首页运营（Banner/公告/消息）、联系店长、预约规则（全局）、学习助手/知识库/错题本、上岸集市、系统状态与迁移。

店长首版不开放全站用户管理。

## 鉴权

- 登录 JWT 仍为 `admin:{id}`；登录响应带 `role`、`store_id`、`store_name`
- `assert_hq` / `assert_store_access(admin, store_id)`；列表强制本店过滤
- 改 URL 或篡改 `store_id` → 403

## 非目标

店员角色、一人多店、字段级权限。
