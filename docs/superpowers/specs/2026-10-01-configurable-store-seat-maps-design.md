# 分店可配置座位图设计

日期：2026-10-01  
状态：待书面确认

## 背景与目标

用户希望在现有小程序增加由姐姐独立经营的分店。新店的座位平面图尚未确定，希望日后由后台上传、标注座位并替换，而无须再次修改小程序代码。两店共用顾客入口，但各自的座位、价格、订单、管理权限和收款归属应独立。姐姐的公司商户号仍在申请前；本设计聚焦第一阶段的门店座位图配置，支付与经营数据隔离是随后独立交付的阶段，新店在它们完成前不得对顾客开放。

成功标准：后台能为新店上传平面图、创建区域和座位、拖动座位标记、预览并发布；小程序按所选门店显示已发布图与实时座位状态；更换图片或移动标记不改变既有订单对应的座位；未配置或未获准营业的新店不出现在顾客门店列表。现有门店仍使用原有布局，预约体验不变。

## 方案选择

采用“每店背景图片 + 数据化座位标记”。后台保存图片、区域、座位编号及相对坐标；小程序把实时座位状态叠加在图片上。相对坐标以 0–100% 表示，可适应不同屏幕尺寸。该方案让新店以后换图和调座位位置都通过后台完成。

备选方案是继续为每家店编写固定的墙体与座位布局；每次变更都要改代码、发版。完整绘图编辑器可绘制墙体和房间，但当前需求只需上传已定稿的平面图，不引入该复杂度。

## 范围与阶段边界

本阶段完成座位图配置与顾客端显示，并增加新店草稿/营业开关。后台可为不同门店配置不同数量与编号的座位。座位图尚未上传时，后台可保存门店资料，但顾客不可预订该店。

本阶段不接通姐姐公司的商户号，不开放她的店给顾客，也不赋予她后台账号。独立商户支付、门店管理员权限、余额/卡券隔离、逐店报表作为下一阶段的单独设计与实现；这些完成并验收后才可将新店设为营业。门店已存在的营业时间和价格配置保持现状，但开放新店时必须逐项检查。

## 数据与兼容

- `Store` 增加座位图模式与发布状态。现有门店迁移为 `legacy`，继续使用固定 28 座图；新店默认 `image` 且未发布、停业。现有 `floor_plan` 字段承载已发布图片路径，图片 URL 由服务端生成。
- 图片模式使用独立的座位图草稿数据，包含图片路径、宽高比、各座位 `seat_id` 的相对坐标和显示方向。发布时一次性将完整草稿切换为已发布版本；顾客不会看到上传了新图但标记仍是旧位置的中间状态。已发布版本保留以便恢复上一版。
- `Seat` 继续是座位身份的唯一来源，预约仍引用 `seat_id`。图片模式可使用任意本店唯一编号，不再套用现店 1–28 的过滤与编号映射。区域从该店的 `Zone` 读取。座位 `status` 控制启停；草稿中新建但尚未发布的座位不可预订。
- 换图或移动标记不删除/重建座位。对已有预约的座位只能停用，不物理删除；历史订单始终可按原 `seat_id` 查询。已发布图中不再出现的座位不可产生新预约。
- 现店的固定补座功能只在 `legacy` 模式可用，不能对图片模式自动生成 28 个座位或重置其坐标。

## 后端与接口

- 管理接口按门店读取座位图草稿和已发布版本；上传图片、更新草稿中的座位与坐标、预览、发布、恢复上一版。所有写入校验门店、区域和座位归属，编号本店唯一、坐标在画布范围内，图片格式与大小沿用现有上传约束，并写入管理员操作日志。
- 顾客接口按门店返回已发布图片、画布比例、座位标记及座位状态。未发布的图片模式门店不对顾客提供可订座位；预约创建时在服务端再次校验该座位属于该门店、已发布且启用，不只依赖前端隐藏。
- 将 `/store/{id}/seats`、`availability`、换座候选及后台选座逻辑中全局 1–28 编号过滤改为按门店模式选择。`legacy` 路径保留现有行为；`image` 路径只处理该店已发布的座位 ID。
- 新建门店默认为停业。发布座位图并不自动将门店设为营业；营业状态需在支付、价格和权限验收后单独开启。

## 管理后台与小程序

- 在“座位管理”按门店展示两种模式。现店继续显示原有标准座位管理；图片模式显示上传区、草稿画布、区域与座位列表、拖动定位、预览和发布。更换图片后先在草稿中校对点位，确认后统一发布。后台明确展示“未发布”和“营业中”是两个不同状态。
- 小程序选座页从门店接口获取布局模式。现店继续原来的房间图；图片模式显示该店的背景图和服务器给出的座位标记，保留缩放、状态颜色、选座与确认交互。座位总数根据该店已发布且有效的座位计算，不使用固定常量。
- 图片加载失败或布局缺失时显示不可预约提示，不能退回到现店的 28 座图，以免误订。

## 验证与上线

1. 迁移后现店 28 座、选座、换座、预约、后台补座行为保持一致。
2. 新建停业门店，不上传平面图时顾客列表不可见、服务端拒绝预约。
3. 新店上传任意比例的图片、建立非 1–28 编号座位、拖动并发布；小程序在不同屏幕尺寸下显示正确且可选座。
4. 替换背景图并调整部分标记后发布；既有订单仍指向原座位，未发布草稿不影响顾客。
5. 停用有历史订单的座位后无法新订，订单历史仍可查询；重复编号、越界坐标、跨店座位或区域均被拒绝。
6. 真实开店前另行验收姐姐店的支付、退款、价格、后台权限和报表；本阶段不将其设置为营业。
